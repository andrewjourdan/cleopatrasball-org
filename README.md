The Four Hebs is a concept for a year-long series of performances of William Shakespeare's Antony and Cleopatra, staged at each change of season along the road Egypt's obelisks travelled. Two obelisks known as Cleopatra's Needle stand in Central Park and on London's Victoria Embankment. A third stands on the Place de la Concorde in Paris, and its twin still stands at the gate of Luxor Temple. The tour follows that road in reverse and finishes where the stones began.

Heb (ḥb) is the ancient Egyptian word for festival. Each season of the tour is one heb, and each is planned to raise funds for the theaters, parks, museums and preservation organizations of its host city.

Hosting

The site is served by GitHub Pages from the root of the main branch, with the custom domain cleopatrasball.org. Requests to www.cleopatrasball.org redirect to it. HTTPS uses a Let's Encrypt certificate issued and renewed by GitHub Pages. DNS is managed through Cloudflare. No build step is required.

A subpage is a folder containing an index.html file. For example, patronage/index.html becomes cleopatrasball.org/patronage/.

Editing notes
Both pages declare UTF-8 and write special characters as character codes so they display correctly on any server.
In the page text, use HTML codes such as &#183; for ·.
Inside a <style> block, use CSS codes such as \2197 for ↗. HTML codes are not translated inside a stylesheet and appear as literal text.
Cloudflare's Email Obfuscation feature rewrites email addresses on the pages. Turn it off in the Cloudflare dashboard so the inquiry address appears as written.

## For developers

### Local preview

Use Python 3.12 or newer for the documented commands. This static site has no package installation or build step.
From the repository root, run:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000/; stop the preview with Ctrl+C. Also open http://localhost:8000/patronage/.
An internet connection is needed for externally loaded fonts.

### Validation and publishing


The preferred URL is https://cleopatrasball.org/; the patronage page is https://cleopatrasball.org/patronage/.

Run `python3 scripts/check_site.py` before submitting changes. GitHub Actions runs the same checks on pull requests and main. Check mobile and desktop layouts and countdown behavior around the event time before publishing.

Repository settings: protect main with pull requests, block force pushes and deletion, and require the Site checks job after its first successful run. For a sole maintainer, do not require another person's approval. Enable automatic deletion of merged branches. Use the root domain as the repository homepage.

Launch verification: confirm Pages publishes main from the root; enforce HTTPS; verify root and www redirect behavior and Cloudflare DNS; verify inquiry mailbox delivery with a real inbound test. A mailto link does not prove mailbox delivery.
